# Meta Selector

Проект для автоматического выбора алгоритмов классификации табличных данных с использованием мета-обучения.

Программа анализирует характеристики датасетов, извлекает метапризнаки с помощью PyMFE и запускает простые классификаторы (Logistic Regression, Decision Tree, kNN, Naive Bayes, LDA) для оценки структуры данных.

На основе полученных характеристик и результатов TabArena формируется метадатасет для обучения мета-модели, которая прогнозирует разницу в качестве современных алгоритмов классификации, включая TabPFN и TabICLv2.

Проект поддерживает загрузку и проверку датасетов, воспроизводимые разбиения данных и оценку мета-моделей методом Leave-One-Dataset-Out (LODO).

## Установка и тесты

После клонирования создайте окружение в текущем каталоге проекта:

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[test]"
.venv/Scripts/python.exe -m pytest -q
```

Не переносите `.venv` между checkout-каталогами: editable-установка содержит
абсолютный путь к `src`. После перемещения проекта пересоздайте окружение или
повторите установку из нового каталога. `pythonpath` pytest действует только
в процессе pytest и не заменяет установку для дочерних Python-процессов.
Проверить установленный путь можно командой
`.venv/Scripts/python.exe -I -c "import meta_selector; print(meta_selector.__file__)"`.

Утверждённые `data/raw/pmlb_*/*.csv` хранят точные байты оригиналов из
`data/PMLB/`; `.gitattributes` отключает для них преобразование LF/CRLF.
При восстановлении копий сверяйте SHA-256 с `metadata.yaml` и конфигурацией
пилота. Не обновляйте ожидаемые хеши из-за конвертации окончаний строк.
