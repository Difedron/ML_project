# Meta Selector

Проект для автоматического выбора алгоритмов классификации табличных данных с использованием мета-обучения.

Программа анализирует характеристики датасетов, извлекает метапризнаки с помощью PyMFE и запускает простые классификаторы (Logistic Regression, Decision Tree, kNN, Naive Bayes, LDA) для оценки структуры данных.

На основе полученных характеристик и результатов TabArena формируется метадатасет для обучения мета-модели, которая прогнозирует разницу в качестве современных алгоритмов классификации, включая TabPFN и TabICLv2.

Проект поддерживает загрузку и проверку датасетов, воспроизводимые разбиения данных и оценку мета-моделей методом Leave-One-Dataset-Out (LODO).
