# Как добавить новый датасет

Для планируемых 150 датасетов путь остаётся тем же: `data/raw/<dataset_id>/`,
metadata — `data/raw/<dataset_id>/metadata.yaml`. Регистрация не запускает модели.
После отдельной команды результаты пяти простых моделей сохраняются в
`data/derived/landmarkers/custom_landmarkers.parquet`, обычные метапризнаки — в
`data/derived/meta_features/meta_features.parquet`, результаты кандидатов — в
`data/derived/candidate_scores/candidate_scores.parquet`. Splits находятся в
`data/splits/<dataset_id>/holdout_0.json`; raw не изменяется.
Команды, параметры и разделение standard/custom landmarks:
[RESEARCH_PIPELINE.md](RESEARCH_PIPELINE.md).

Эта инструкция для Дианы и Риты. Для добавления датасета менять Python-код не нужно.
Датасеты скачиваем самостоятельно: автоматического скачивания в проекте пока нет.

Допустим, вы нашли на Kaggle файл `credit_card_fraud.csv`. В нём столбец `Class`
содержит правильные ответы — например, `0` и `1`. Это **пример названия**, а не
догадка проекта: нужный столбец вы определяете по описанию источника.

## 0. Один раз подготовьте окружение

Откройте терминал в корне проекта — там, где находится `README.md`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
```

В следующих терминалах достаточно `source .venv/bin/activate`.
Для Windows PowerShell активация: `.venv\Scripts\Activate.ps1`.

## 1. Скачайте датасет

Скачайте исходный файл из OpenML, Kaggle, UCI или другого источника.
Если он находится в ZIP, самостоятельно распакуйте нужную таблицу. Архивы,
несколько связанных таблиц и автоматическое объединение таблиц пока не поддерживаются.

Сохраните ссылку на источник и его идентификатор. Убедитесь, что условия источника
позволяют использовать данные в вашей работе. Код по этой ссылке ничего не скачивает.

## 2. Придумайте постоянный dataset_id и создайте папку

```text
data/raw/credit_card_fraud/
```

Правила имени:

- Строчные латинские буквы, цифры, слова через одно подчёркивание.
- Начинайте с буквы. Начальный `_` разрешён для тестовых наборов, как `_toy_binary`.
- Без пробелов, дефисов, кириллицы и фрагментов пути.
- Примеры: `adult`, `bank_marketing`, `credit_default`, `heart_disease`.
- Имя должно оставаться стабильным и совпадать с `dataset_id` в метаданных.

Перед добавлением проверьте список: `python scripts/list_datasets.py`.
Если это тот же набор или другая его версия, сначала договоритесь, нужен ли новый ID.
Система не определяет автоматически, что два разных файла являются одним датасетом.

## 3. Положите исходный файл в эту папку

Можно оставить скачанное имя:

```text
data/raw/credit_card_fraud/credit_card_fraud.csv
```

Или использовать единообразное `data.csv`, если вам так удобнее:

```text
data/raw/credit_card_fraud/data.csv
```

Для других форматов расположение такое же:

```text
data/raw/my_dataset/data.csv
data/raw/my_dataset/data.xlsx
data/raw/my_dataset/data.parquet
```

В `metadata.yaml` будет указан **один** файл. Не помещайте файл в `src/`, `scripts/`
или `data/registry/`. `data/processed/<dataset_id>/` зарезервирован для следующего
этапа и сейчас не заполняется автоматически.

## 4. Создайте metadata.yaml и явно укажите target

В той же папке создайте обычный текстовый файл с точным именем `metadata.yaml`:

```yaml
dataset_id: credit_card_fraud
name: Credit Card Fraud
task_type: classification
target: Class

source:
  type: kaggle
  url: "https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud"
  external_id: "mlg-ulb/creditcardfraud"

file:
  name: data.csv
  format: csv
  separator: ","
  encoding: utf-8
  sheet_name: null

problem:
  type: binary

notes: "Target Class описан в источнике: 0 — обычная операция, 1 — мошенничество."
```

Если оставили оригинальное имя, измените `file.name` на `credit_card_fraud.csv`.
Пример не означает, что этот датасет уже добавлен в проект.

**Где написать target:** в строке `target:` файла `data/raw/<dataset_id>/metadata.yaml`.
Например, для целевой колонки `class`:

```yaml
target: class
```

Регистр и пробелы важны: `Class`, `class` и `class ` — разные имена.
Если имя отсутствует в таблице, проверка покажет доступные колонки.
Проект никогда не выбирает последнюю колонку, `class`, `label` или другую колонку
автоматически. Без явно заданного target проверка завершается ошибкой.

### Что означают поля

| Поле | Что написать |
|---|---|
| `dataset_id` | Точное имя папки |
| `name` | Понятное название для людей |
| `task_type` | Сейчас только `classification` |
| `target` | Точное имя целевой колонки |
| `source.type` | Обычно `openml`, `kaggle`, `uci` или `other`; допустим другой непустой тип |
| `source.url` | Ссылка на исходную страницу; если её нет, `""` |
| `source.external_id` | Идентификатор в источнике строкой или `null` |
| `file.name` | Имя файла в той же папке, без пути |
| `file.format` | `csv`, `xlsx` или `parquet` |
| `file.separator` | Один символ разделителя CSV |
| `file.encoding` | Кодировка CSV |
| `file.sheet_name` | Имя или индекс листа XLSX; `null` — первый |
| `problem.type` | `binary` для двух классов, `multiclass` для трёх и более |
| `notes` | Замечания об источнике и данных; можно `""` |

Основные поля и секции обязательны. `external_id` можно опустить или указать `null`;
`notes` можно опустить. Неизвестные параметры не используются. Повторяющиеся YAML-ключи
считаются ошибкой, чтобы второе объявление `target` не перезаписало первое незаметно.

### Если CSV использует точку с запятой или другую кодировку

```yaml
file:
  name: original.csv
  format: csv
  separator: ";"
  encoding: cp1251
  sheet_name: null
```

Разделитель должен быть ровно одним символом; для табуляции используйте `"\t"`.
Кодировка должна соответствовать файлу. Проект не угадывает ни разделитель,
ни кодировку. Без этих параметров используются запятая и UTF-8.

### Если файл XLSX

```yaml
file:
  name: data.xlsx
  format: xlsx
  separator: ","
  encoding: utf-8
  sheet_name: null
```

`null` означает первый лист. Чтобы выбрать другой, укажите точное имя:

```yaml
  sheet_name: Data
```

Или индекс с нуля: `sheet_name: 1` — второй лист. Список листов не поддерживается.
`separator` и `encoding` для XLSX игнорируются. Первая строка выбранного листа —
заголовки колонок. Формулы Excel не пересчитываются: читаются сохранённые значения.

### Если файл Parquet

```yaml
file:
  name: data.parquet
  format: parquet
  separator: ","
  encoding: utf-8
  sheet_name: null
```

Параметры CSV и Excel для Parquet игнорируются. Нужен один Parquet-файл, а не
каталог из нескольких частей.

## 5. Проверьте датасет

```bash
python scripts/validate_dataset.py credit_card_fraud
```

Команда проверяет метаданные, файл, заголовки, target, непустую таблицу,
наличие признаков и минимум двух классов. Она ничего не регистрирует и не изменяет
исходные данные.

Смотрите строку `Status`. `VALID` означает, что датасет подходит для дальнейших
этапов инфраструктуры. Это не научная оценка качества данных и не гарантия
пригодности для конкретной будущей модели.

NaN, категории и дисбаланс допустимы. Пропуски в target тоже сохраняются и
показываются предупреждением; перед обучением мы отдельно решим, как их обработать.
Классы считаются по непустым значениям target. Если остаётся менее двух классов,
проверка не проходит.

## 6. Зарегистрируйте датасет

```bash
python scripts/register_dataset.py credit_card_fraud
```

Команда повторно проверит данные и добавит или обновит одну запись в:

```text
data/registry/datasets.csv
```

Повторная регистрация не создаёт вторую строку с тем же ID. Невалидный датасет тоже
может быть зарегистрирован — со статусом и описанием ошибки.

## 7. Убедитесь, что датасет появился

```bash
python scripts/list_datasets.py
```

Список показывает сохранённый индекс, а не перечитывает большие таблицы при каждом
вызове. После изменения файла или метаданных повторите регистрацию.

## Как восстановить весь реестр

```bash
python scripts/register_dataset.py --rebuild
```

Команда заново просматривает папки `data/raw/`, читает метаданные, проверяет файлы
и пересоздаёт индекс. Его можно удалить и получить снова с теми же байтами, если
данные, метаданные, конфигурация и окружение чтения не изменились.

Ошибка одного набора не блокирует добавление остальных в индекс. Папка без
`metadata.yaml` тоже попадёт в реестр с ошибкой. Скрытые служебные папки пропускаются.
Если отсутствует весь `data/raw/`, получится пустой CSV с заголовком.

Реестр не является источником истины и не содержит timestamps. Строки отсортированы
по ID. Новая версия сначала полностью записывается во временный файл рядом с
реестром, затем атомарно заменяет предыдущую.

## Статусы и ошибки

| Статус | Что означает | Что делать |
|---|---|---|
| `valid` | Основные проверки пройдены | Можно зарегистрировать набор |
| `invalid_metadata` | Нет метаданных, target, неверный ID или настройки | Исправить `metadata.yaml` |
| `missing_file` | Метаданные корректны, но локального файла нет | Скачать и положить указанный файл |
| `invalid` | Таблица не читается или не проходит структурные проверки | Прочитать ошибку и исправить источник/описание |

Проблемы с конфигурацией всего проекта или записью реестра выводятся отдельно.
Коды команд: `0` — успешно, `1` — есть невалидные данные, `2` — ошибка выполнения.
После `--rebuild` с кодом `1` индекс всё равно записан, включая проблемные наборы.

### «Target отсутствует в таблице»

Сверьте имя целевой колонки, разделитель CSV и выбранный лист Excel. Не меняйте
исходный файл только ради того, чтобы скрыть ошибку: сначала исправьте метаданные.

### «Повторяющиеся исходные названия колонок»

В таблице есть, например, два столбца `age`. Проверка обнаруживает их до того,
как pandas превратит второй в `age.1`. Проект сам ничего не переименовывает.
Нужен исправленный источник либо отдельное согласованное решение о нормализации.

### «Файл не найден» после git clone

Это ожидаемо для реальных данных: Git содержит их описание, а не тяжёлые файлы.
Скачайте исходный файл вручную по ссылке в `source.url` и положите под именем
из `file.name`. Затем зарегистрируйте набор снова.

## Что хранить в Git

**Храним:** код, конфигурации, документацию, все `metadata.yaml`, производный
`datasets.csv`, `.gitkeep` и весь маленький пример `_toy_binary`.

**Не храним:** CSV/XLSX/Parquet и другие payload-файлы реальных наборов,
содержимое `data/processed/`, результаты вычислений, кеши и виртуальное окружение.
Правила действуют и для оригинальных имён, а не только для `data.csv`.

Не используйте `git add -f` для больших или закрытых данных. Метаданные не должны
содержать пароли, API-токены или приватные ссылки с секретными параметрами.
Toy-пример намеренно исключён из игнорирования и доступен сразу после клонирования.

## Если терминал открыт в другой папке

Укажите абсолютные пути к интерпретатору и скрипту:

```bash
/path/to/project/.venv/bin/python /path/to/project/scripts/validate_dataset.py my_dataset
```

Остальные пути будут взяты из файлов проекта. Запись `python scripts/...` работает
из корня проекта, потому что сам Python должен сначала найти этот скрипт.

## Что происходит с исходными данными

Ни validate, ни register, ни list не записывают исходный файл. Нет удаления строк,
заполнения NaN, изменения target, масштабирования, переименования колонок или
кодирования категорий. CSV читается с обычным распознаванием типов и пропусков pandas;
это чтение таблицы, а не глобальный preprocessing. Parquet и XLSX также не пересохраняются.
